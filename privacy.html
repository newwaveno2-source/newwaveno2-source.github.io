1. このアプリについて

「AI美少女図鑑アップローダー」（以下「本アプリ」）は、YouTubeチャンネル「AI美少女図鑑」の運営者本人が、自身のチャンネルへ動画を投稿する作業を自動化するために作成した個人用ツールです。第三者への提供や一般公開は行っていません。

2. 利用するGoogleユーザーデータ

本アプリは、運営者本人のGoogleアカウントでのみログインし、YouTube Data API を通じて次の操作を行います。

  • 運営者自身のチャンネルへの動画のアップロード（タイトル、概要欄、タグ、公開予約日時の設定を含む）
  • サムネイル画像の設定
  • 運営者自身の再生リストへの動画の追加
  • 運営者自身のチャンネル情報・再生リスト情報の参照

3. データの保存と利用

認証情報（アクセストークン・更新トークン）は、運営者本人のパソコン内にのみ保存されます。取得した情報は、上記の投稿作業を行う目的にのみ利用し、それ以外の目的（広告、分析、販売など）には利用しません。

4. 第三者への提供・共有

本アプリが取得したGoogleユーザーデータを、第三者に提供・販売・共有することはありません。外部のサーバーへ送信・蓄積することもありません。

5. Google API サービスのユーザーデータポリシー

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータポリシー に準拠します。また、YouTube 利用規約 および Google プライバシーポリシー に従います。

6. アクセス権の取り消しとデータの削除

運営者は、いつでも Google アカウントのアクセス権の管理ページ から本アプリのアクセス権を取り消すことができます。あわせて、パソコン内に保存された認証情報ファイルを削除することで、保存データはすべて消去されます。
